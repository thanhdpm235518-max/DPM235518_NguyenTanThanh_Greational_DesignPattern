II. Tạo Personal Access Token (PAT) trên GitHub

GitHub không cho phép dùng mật khẩu thông thường để push code. Bạn cần tạo Personal Access Token thay thế.

  1. Đăng nhập vào https://github.com
  2. Nhấn vào ảnh đại diện góc trên phải → chọn Settings
  3. Kéo xuống cuối menu bên trái → chọn Developer settings
  4. Chọn Personal access tokens → Tokens (classic)
  5. Nhấn Generate new token → Generate new token (classic)
  6. Điền thông tin:
    • Note: push-code (đặt tên bất kỳ)
    • Expiration: Chọn thời hạn (ví dụ: 90 days)
    • Select scopes: Tick vào ô repo (toàn bộ)
  7. Nhấn Generate token
  8. SAO CHÉP TOKEN NGAY — Token chỉ hiện 1 lần duy nhất!
⚠ Lưu ý quan trọng:
Token chỉ hiển thị một lần sau khi tạo. Hãy sao chép và lưu lại ngay vào Notepad hoặc nơi an toàn trước khi đóng trang.

III. Tạo Repository trên GitHub

  1. Đăng nhập vào https://github.com
  2. Nhấn nút "+" góc trên phải → chọn "New repository"
  3. Điền thông tin repository:
    • Repository name: DPM235518_NguyenTanThanh_Tuan01_Creational_Design_Pattern
    • Description: Creational Design Patterns - C# (tùy chọn)
    • Visibility: Chọn Public hoặc Private
    • KHÔNG tick "Add a README file", "Add .gitignore", "Choose a license"
  4. Nhấn "Create repository"
ℹ Lý do không tick README: Vì code đã có sẵn trên máy tính, nếu tạo README trên GitHub sẽ gây xung đột lịch sử commit khi push lên.

IV. Các Bước Push Code Lên GitHub

Mở PowerShell (hoặc Terminal trong Visual Studio Code), cd đến thư mục dự án rồi thực hiện lần lượt các bước sau:

Bước 1: Khởi tạo Git Repository

Lệnh này tạo thư mục .git — bộ nhớ lịch sử của Git trong dự án.

git init

Kết quả mong đợi: Initialized empty Git repository in ...

Bước 2: Tạo file .gitignore

File .gitignore giúp Git bỏ qua các thư mục bin/, obj/, .vs/ (file biên dịch, không cần thiết phải đẩy lên GitHub).

Tạo file .gitignore tại thư mục gốc với nội dung:

bin/
obj/
.vs/
*.user
*.suo
packages/
.DS_Store
Thumbs.db

Bước 3: Thêm toàn bộ file vào Staging Area

Lệnh này đánh dấu tất cả file để chuẩn bị commit.

git add .

Bước 4: Tạo Commit đầu tiên

Commit là một "ảnh chụp" trạng thái code tại thời điểm này, kèm theo thông điệp mô tả.

git commit -m "Initial commit: Creational Design Patterns - Factory, Builder, Abstract, Prototype, Singleton"

Kết quả mong đợi: danh sách các file được tạo (create mode 100644 ...).

Bước 5: Đổi tên nhánh thành main

GitHub mặc định dùng nhánh main (thay vì master cũ).

git branch -M main

Bước 6: Kết nối với Repository GitHub

Lệnh này liên kết repo trên máy tính với repo trên GitHub.
Thay YOUR_USERNAME bằng tên tài khoản GitHub của bạn. 

git remote add origin https://github.com/YOUR_USERNAME/DPM235518_NguyenTanThanh_Tuan01_Creational_Design_Pattern.git

Ví dụ cụ thể:

git remote add origin https://github.com/NGUYENVANTHANG-DPM235479/DPM235518_NguyenTanThanh_Tuan01_Creational_Design_Pattern.git

Bước 7: Push Code lên GitHub

Lệnh này đẩy toàn bộ code lên GitHub lần đầu tiên.

git push -u origin main

Hệ thống sẽ hỏi:

  • Username: Nhập tên tài khoản GitHub (ví dụ: NGUYENVANTHANG-DPM235479)
  • Password: Dán Personal Access Token đã tạo ở Phần II (không nhập mật khẩu thường)

Kết quả mong đợi:

* [new branch]      main -> main
branch 'main' set up to track 'origin/main'.

VI. Cách Push Lần Sau (Khi Có Thay Đổi)

Mỗi khi chỉnh sửa code và muốn cập nhật lên GitHub, chỉ cần 3 lệnh:

# 1. Thêm các file thay đổi vào staging
git add .

# 2. Tạo commit với mô tả thay đổi
git commit -m "Mô tả nội dung thay đổi"

# 3. Push lên GitHub
git push
ℹ Mẹo đặt tên commit:
Nên đặt tên commit rõ ràng, ví dụ:
"Add Singleton pattern"
"Fix bug in AbstractFactory"
"Update README"

VII. Xử Lý Lỗi Thường Gặp

Lỗi Nguyên nhân Cách xử lý
Authentication failed Sai username hoặc token Kiểm tra lại username và dùng Personal Access Token thay mật khẩu
remote origin already exists Đã thêm remote trước đó Chạy: git remote set-url origin [URL mới]
rejected - non-fast-forward GitHub có commit mà máy chưa có Chạy: git pull origin main --rebase rồi push lại
not a git repository Chưa chạy git init Chạy lại Bước 1: git init
Push thành công nhưng không thấy file File bị .gitignore loại trừ Kiểm tra file .gitignore, dùng git status để xem
